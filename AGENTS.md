# Repository Agent Instructions

## Git, PR, and Deployment SOP

For every future task in this repository, unless the user explicitly directs otherwise:

- Branch from the latest `main`.
- Never make implementation changes directly on `main`.
- Commit changes to the working branch.
- Push the branch.
- Create a pull request targeting `main`.
- Use the Vercel preview deployment to verify the work when available.
- Return the pull request link and Vercel preview link when work is complete.
